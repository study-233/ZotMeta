# ZotMeta 2.1.2

适用于 Windows 上的 Zotero 10.0.7。此版本沿用原设置页和控制面板布局，提供简体中文、英文和随 Zotero 外观切换的深浅配色。

- 元数据服务返回 HTTP 429 时，同一服务的批量请求共享冷却时间。插件会遵守 `Retry-After`；服务未指定时间时，退避从 2 秒开始，上限为 30 秒。其他数据源仍可查询。每条最多自动重试一次。超出该批次 10 秒的限流重试窗口时，调试日志会提示稍后重试。
- 期刊条目经原有 PDF 标识符提取流程仍缺少可用标识符时，直接报告缺少哪些标识符。图书缺少 ISBN 时也会直接报告。
- 批量更新的失败日志含批次编号、条目编号、更新前的标题和各来源的失败原因。成功保存的 arXiv 预印本和整个批次的结果也可在调试日志中核对。
- arXiv 的期刊引用写入 Extra 的 `arXiv journal ref` 行。重复更新会保留原有备注和其他字段。

## 安装

下载 `zotmeta-2.1.2.xpi`，在 Zotero 的“工具 → 插件”中打开齿轮菜单，选择“从文件安装插件…”。安装包沿用 ZotMeta 的插件 ID，会替换已安装的同名插件。随包提供 SHA-256 校验文件。

包内保留 Zotero 安装器要求的上游更新地址。此定制包启动时会关闭 ZotMeta 自身的后台自动更新。
